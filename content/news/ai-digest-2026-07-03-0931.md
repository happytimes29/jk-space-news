## 📰 1. GitHub is proud to announce that you can now obtain your public repo on CD-ROM

🔗 [原文連結](https://forms.cloud.microsoft/pages/responsepage.aspx?id=v4j5cvGGr0GRqy180BHbR6G-c11n8yFDlQmk4B-QjDxUQkdTTjZLU0EyTFFRV1E3NVRTVTRTWjRHMy4u&route=shorturl)

TITLE:GitHub 宣布可以將你的公開儲存庫燒成 CD-ROM 寄給你

還記得當年用光碟裝軟體、裝遊戲的年代嗎？GitHub 最近丟出一個超懷舊的消息：他們很驕傲地宣布，你可以申請把公開儲存庫（public repo）的內容燒錄到 CD-ROM 上，然後郵寄給你。對，你沒看錯，就是那個你以為已經消失在歷史灰塵裡的圓形塑膠片。

## 原文摘要：科技巨頭的浪漫惡搞？

根據官方公告，這項服務主要用於「讓開發者擁有程式碼的實體副本」，聽起來很像是在開玩笑，但 GitHub 確實認真地架設了申請表單。你可以選定一個公開儲存庫，他們會把整個 repo（包括版本歷史）壓縮後燒進光碟，再用普通的郵件寄到你家。當然，這顯然不是為了取代 git clone，而是一種限量的、帶有復古情懷的紀念品。

不過要注意，目前僅限「公開儲存庫」，而且可能只侷限於檔案總大小不超過 700MB（CD-ROM 容量上限）的專案。大型專案大概就只能等 DVD 版本（如果真的有的話）。

## 我的觀點：這是效率的倒退，還是記憶的載體？

這項服務絕對不是為了實用性。任何人想要備份程式碼，用 GitHub 的 zip 下載或 git clone 都比等郵局寄光碟快上幾千倍。但換個角度想，這其實是對數位時代資訊易逝性的一種反諷——當一切都存在雲端、隨時可能被刪除或改版時，一張實體光碟反而是最「永恆」的保存方式。我贊成這種浪漫主義的嘗試，但同時也質疑它的可行性：現在有多少電腦還有光碟機？而且光碟的壽命遠比雲端備份短。

不過，如果你是那種喜歡收藏實體週邊的開發者，拿到一張印著你自己 repo 名字的 CD-R，上面還有燒錄痕跡，那種滿足感可能比在 GitHub 上獲得星星還強烈。這種「儀式感」正是現代軟體開發最缺乏的東西。

## 延伸思考：數位懷舊與備份的兩難

這起事件讓我想起另一個現象：近年來越來越多人開始把重要資料燒錄到光碟或存入磁帶，對抗所謂的「數位黑洞」。GitHub 這個舉動或許不是真的要推廣 CD-ROM 備份，而是提醒我們：所有雲端服務都可能消失（看看 Google 砍掉了多少服務），但一張光碟只要不被刮傷，至少能活個十幾二十年。

不過，真要嚴肅討論備份，CD-ROM 顯然不是最佳解。現代備份首選還是異地多份雲端備份加上本地 NAS。但偶爾來一點這種「不務正業」的服務，反而讓開發社群更有話題性。如果 GitHub 真的把這項服務常態化，搞不好會成為開發者之間送禮的奇特選擇——「嘿，我把你的開源專案燒成光碟了，生日快樂！」

> 📝 編輯說：:這篇文章在 Hacker News 上引發兩極討論，有人覺得是浪費資源的噱頭，也有人認為是數位保存的最佳浪漫。筆者覺得最有價值的觀點是：當一切都在雲端時，實體媒介反而成了一種反叛。

## 📰 2. "An AI Job Apocalypse?" – Goldman Sachs Report [pdf]

🔗 [原文連結](https://www.goldmansachs.com/static-libs/pdf-redirect/prod/index.html?path=/pdfs/insights/goldman-sachs-research/an-ai-job-apocalypse/report.pdf&originalQuery=&referrer=)

TITLE: AI工作末日？高盛報告深度解析

## 原文摘要

高盛這份標題超聳動的報告（完整PDF在官網），一開場就扔了個炸彈：生成式AI可能影響全球3億個全職工作，等於美國加歐洲的勞動力快被翻一輪。報告把職業分成「暴露度」等級——律師、會計、財務分析師這類白領，暴露度超標；反倒是建築工、餐飲服務員這類需要物理互動的職業，相對安全。但別急著恐慌，報告也補了一劑強心針：AI能拉高生產力，並像蒸氣機、網際網路一樣，催生全新工作類型。細節還提到，約有三分之二的工作會「部分自動化」，而不是整份消失。

## 我的觀點

3億這個數字太吸眼球，但真正值得看的不是總量，而是「暴露 vs 取代」的微妙差別。報告裡用的詞是exposure（暴露），不是replacement（取代）。意思是，很多任務可以被AI加速或輔助，但整份工作還留著給人類做決策。例如律師審閱合約，AI能三秒抓出條款矛盾，但要不要簽約、如何談判，還是人說了算。風險其實是：那些懂得駕馭AI的人，會慢慢吃掉不會用工具的人的市場。與其說AI是敵手，不如把它當成一把更鋒利的刀——切菜的還是我，只是效率翻倍。

## 延伸思考

報告點到為止，但我覺得最該焦慮的不是就業數字，而是社會的分配機制。當AI讓生產力暴增，財富會集中到掌握算力與資料的巨頭手上，底層勞工如果沒有轉型路徑，差距只會更大。教育體系呢？還在教背誦、填鴨、打字？未來連寫程式都可能被AI代勞，人類該培養的是創意、同理心與跨領域判斷——那些機器很難複製的能力。台灣的製造業與服務業比重高，實體工作雖較安全，但如果你待的是「坐在電腦前處理報表」的職位，真的該開始學點提示工程或數據溝通。以後的面試，大概會問：「你怎麼用AI幫你節省一半時間？」

> 📝 編輯說：: 這篇文章在高盛官網與Hacker News上討論度不高（僅6點），但筆者認為最有價值的觀點是：數字只是煙霧彈，真正的戰場在於「人類如何重新定義工作的邊際價值」。

## 📰 3. Main Street Is Obsessively Watching Nvidia’s Tape as Institutions Quietly Trigger a Nasty 13% Semiconductor Rotation. Why I Am Still Buying

🔗 [原文連結](https://finance.yahoo.com/markets/stocks/articles/main-street-obsessively-watching-nvidia-162328266.html)

TITLE: 散戶緊盯輝達報價，機構卻悄悄引爆13%半導體大屠殺——為何我還在買

## 原文摘要

這幾天半導體圈炸鍋了。散戶們（Main Street）眼睛死盯著輝達（Nvidia）的盤面，心跳跟著每一根K線上下衝。但同一時間，機構投資者已經低調啟動了一波凶狠的板塊輪動，直接把整個半導體族群打趴了13%。這可不是什麼小波動，是紮紮實實的資金大遷徙。作者在標題裡直接說：我還在買。為什麼？因為他認為這波修正只是短期的市場情緒宣洩，長期邏輯根本沒變——AI基礎設施的軍備競賽才剛開始，輝達依然站在暴風眼的正中央。

## 我的觀點

你最近打開券商App，看到輝達那根13%的長黑，心裡第一個念頭是什麼？「完了，高點到了，快逃命。」對吧？很正常，我也是。但如果你仔細看籌碼變化，會發現機構這波賣超其實不是逃命，而是「換手」——把資金從已經漲翻天的AI概念股挪到還沒被炒過頭的半導體設備、記憶體或車用晶片。輝達只是被當成提款機來調節部位，不是基本面出了問題。

我自己這幾天也分批補了一些輝達和台積電ADR。為什麼？因為13%的跌幅把原本過高的本益比修正到相對合理的區間，而AI需求根本沒有減速。你想想，微軟、Google、Meta資本支出還在加碼，資料中心的GPU訂單已經排到明年中，輝達的Blackwell架構又沒對手。這時候被嚇出場，反而中了機構的圈套。

## 延伸思考

這波輪動其實給我們一個很好的教訓：散戶的資訊劣勢在短期波動中被無限放大。我們看的是今天的漲跌，機構看的是三個月後的配置。半導體板塊的週期性本來就很劇烈，一次13%的回調在過去十年裡出現過十幾次，每次事後看都是進場點。真正的風險不是跌13%，而是你在最低點因為恐懼賣掉，然後看著它一個月後漲回來。

另外，這也提醒我們別把所有雞蛋放在同一個籃子裡。半導體裡有設計、製造、設備、材料，不同子領域的輪動節奏不同。如果能學會跟著機構的足跡，在過熱時分批調節，在恐慌時慢慢承接，長期報酬會比死抱單一股票穩定很多。

> 📝 編輯說：: 這篇文章在科技投資社群引發熱議，許多人認為關鍵在於區分「修正」與「反轉」——筆者認為最有價值的觀點是：機構輪動不等於看空，反而可能是下一波多頭的起點。
