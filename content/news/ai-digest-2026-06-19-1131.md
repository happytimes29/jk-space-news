## 📰 1. FedEx inks MOU with China-based airline to boost air cargo network

🔗 [原文連結](https://finance.yahoo.com/economy/articles/fedex-inks-mou-china-based-142800653.html)

TITLE:FedEx與中國航空公司簽署諒解備忘錄 強化航空貨運網絡

## 原文摘要

FedEx宣布與一家中國基礎航空公司簽署諒解備忘錄（MOU），計畫透過新增航線與運能共享，進一步拓展其在亞太地區的航空貨運網絡。雖然具體合作對象與細節尚未完全公開，但此舉被解讀為FedEx在後疫情時代，為了因應跨境電商供應鏈重組與中美貿易結構變化，所進行的戰略布局。該合作預計將顯著提升中國往返北美及歐洲的貨運時效，並降低物流成本。

## 我的觀點：FedEx這步棋，表面是擴張，實際是在「卡位」

這項合作顯示FedEx正在加速從「美國為主」轉向「亞太為核心」的物流戰略。中國的航空貨運市場長期由國營的貨運航空（如中國國際貨運航空）與民營的順豐航空主導，FedEx過去大多依賴自有機隊與合資公司。如今直接與中國本土航空公司簽MOU，等於繞過繁複的航權審批，直接接入中國內需市場。這不只是運力擴張，更是為了對抗UPS與DHL在亞洲的布局，以及中國本土業者（如京東物流、菜鳥）崛起的壓力。

我比較擔心的是，這種合作模式會讓FedEx對中國合作夥伴的依賴加深，一旦中美政策或地緣政治出現波動，貨運鏈的韌性反而會打折。但短期來看，這確實是讓FedEx在中國市場站穩腳跟的最快方式。

## 延伸思考：物流業的「去全球化」與「再全球化」

這則新聞背後藏著一個更大的趨勢：供應鏈正在從「效率優先」轉向「韌性優先」。FedEx選擇與中國航空公司合作，而不是單純擴建自有機隊，說明了全球物流巨頭開始接受「區域化聯盟」的模式。未來可能看到更多「本地夥伴+外資技術」的混合體，類似於航空業的「代碼共享」概念。

另外，這也反映出跨境電商對時效的極致追求——當Temu、SHEIN等平台把出貨時間壓到5天內，物流網路就不能只靠「點對點」直飛，而需要像拼圖一樣，在每個關鍵節點都有備用方案。FedEx這步棋，其實是在為下一個十年的「超即時消費」鋪路。

> 📝 編輯說：: 這篇文章在物流與供應鏈社群引發討論，筆者認為最有價值的觀點是「FedEx藉由MOU繞過航權限制，直接卡位中國內需市場」，這對理解中美物流角力很有幫助。

## 📰 2. AB InBev names Mondelez CEO new chairman

🔗 [原文連結](https://finance.yahoo.com/markets/stocks/articles/ab-inbev-names-mondelez-ceo-090553604.html)

TITLE:百威英博任命億滋國際CEO為新任董事長

## 原文摘要

全球啤酒龍頭百威英博（AB InBev）近日宣布，將任命零食巨頭億滋國際（Mondelez）的執行長Dirk Van de Put為新任董事長。這項人事案預計在2025年股東大會後生效，屆時他將接替即將退休的現任董事長。雖然報導細節不多，但光是「啤酒霸主找餅乾老闆來當董事長」這件事，就已經讓華爾街和消費品圈議論紛紛——畢竟兩家公司一個專注液體酒精，一個專攻固體零食，業務看似八竿子打不著。

## 我的觀點

一個年營收超過500億美元的啤酒帝國，為什麼要找一個巧克力餅乾公司的CEO來坐鎮董事會？這不是亂點鴛鴦譜，而是消費品巨頭在「跨界管理」上的最新賭注。Dirk Van de Put在億滋期間主導了多起併購與品牌年輕化，例如收購 Chipita（歐洲糕點品牌）和推動吉百利無糖巧克力。百威英博顯然看中的不是他的「零食專業」，而是他在「品牌矩陣管理」與「新興市場滲透」上的實戰經驗。這筆任命透露一個訊號：啤酒業的成長天花板已經到了，未來要靠更靈活的品類策略與全球通路整合來突圍。

## 延伸思考

這其實不是第一次消費品巨頭搞「跨界董事」。2018年可口可樂曾挖角寶潔高層當董事，雀巢董事會裡也常見醫藥背景的人。但百威英博這步棋更值得玩味——因為啤酒正在經歷「非酒精化」轉型。他們旗下的無酒精啤酒品牌像 Corona Cero 和 Budweiser Zero 正在快速成長，而億滋在低糖、低卡零食的開發路徑，恰好能提供「如何讓無酒精產品也能賣得像飲料一樣性感」的商業邏輯。說不定未來我們會看到百威推出「啤酒風味餅乾」？玩笑歸玩笑，但這場人事任命背後，其實是傳統產業對「後酒精時代」的提前布局。

> 📝 編輯說：:這篇新聞在LinkedIn上引發跨產業討論，不少分析師認為這是百威英博為下一波併購鋪路。筆者覺得最有價值的觀點是：董事會成員的「行業不對稱性」往往比純同業經驗更能帶來破壞式創新。

## 📰 3. Talos：用于 Lean 的開源 WASM 直譯器

🔗 [原文連結](https://github.com/cajal-technologies/talos)

## 原文摘要

Talos 是一個在 Hacker News 上展示的新專案，本質上是專為 Lean 程式語言設計的開源 WebAssembly（WASM）直譯器。Lean 是微軟研究院開發的定理證明器與函數式語言，過去主要執行在原生環境，而 Talos 的誕生讓 Lean 程式碼能編譯成 WASM 位元碼，然後在瀏覽器或任何支援 WASM 的 runtime 中執行。根據專案說明，Talos 支援 Lean 核心語法、型別推導，甚至能處理部分證明腳本，開發者可以直接在網頁上跑 Lean 的互動式證明。這不僅降低了 Lean 的學習門檻，也打開了形式化驗證應用在 Web 端的大門。

## 我的觀點

你有沒有碰過這種情況：寫了一段形式化驗證的程式，想秀給朋友看，對方卻得先裝一套 Lean 的開發環境？Talos 直接解決這個痛點。它把 Lean 塞進 WASM 沙箱裡，意味着你只要打開瀏覽器就能執行證明腳本——不用下載、不用安裝、不用跟路徑變數搏鬥。這對教學場景特別實用，想想看，一堂離散數學課，學生點個連結就能直接操作 Lean 證明，教授不用花半節課 debug 環境問題。更進階的是，Talos 宣稱能處理「部分證明腳本」，這表示它可能保留了 Lean 的互動式證明機制，而不只是單純的計算器；你能在網頁上逐步展開證明樹、檢查策略應用，這體驗跟本機幾乎沒差。當然，WASM 直譯器效能一定不如原生編譯，但對於一小時跑一次的形式化驗證，延遲根本不是問題。我認為這個專案最大的亮點不是效能，而是「普及性」——它把原本小眾的形式化方法拉到 Web 生態系，搞不好能催生出一堆線上協作證明工具。

## 延伸思考

Talos 讓我想起更宏觀的趨勢：WASM 正在吃掉所有語言的執行層。從 C/C++、Rust 到 Python，現在連定理證明器也上車了。這代表什麼？代表未來我們可能會看到「形式化驗證即服務」的商業模式——你寫一段 Lean 契約，公司把它編譯成 WASM，然後掛在 AWS Lambda 或 Cloudflare Workers 上當作微服務來跑。更激進一點，結合區塊鏈上的智慧合約，用 Lean 證明合約沒有漏洞，然後透過 Talos 在 EVM 裡執行？雖然聽起來有點科幻，但技術路徑是通的。當然，目前 Talos 還在早期階段，文件可能不太齊，社群是否會圍繞它發展工具鏈才是關鍵。如果你對形式化方法有興趣，又愛玩 Web 技術，現在去 GitHub 上 fork 一下絕對值得——哪怕只是為了在瀏覽器裡打一條 `theorem hello : 1 + 1 = 2 := by native_dec` 然後截圖炫耀。

> 📝 編輯說：: 這篇文章在 GitHub 與 Hacker News 上引發不少討論，不少 Lean 用戶抱怨 WASM 直譯器無法完整支援策略導向的證明，但普遍看好它降低入門門檻的潛力。筆者認為 Talos 最有價值的觀點是「讓形式化驗證走向大眾」，這點倒是沒人反對。
