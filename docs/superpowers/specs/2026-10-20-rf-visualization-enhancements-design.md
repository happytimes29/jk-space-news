# JK Space RF 工具即時示意圖與衰減器體驗強化設計規格

**日期：** 2026-10-20  
**狀態：** 書面規格待站主審閱  
**依賴：** `docs/superpowers/specs/2026-10-19-jk-space-engineering-rf-tools-v1-design.md`  
**範圍：** 強化既有被動電路、RF 快速計算、Smith 圖與 PCB 傳輸線工具的即時圖形、RF 用詞、錯誤狀態與三語體驗

## 1. 背景與目標

第一版工程工具已提供 T／π 型衰減器、RF 傳播與反射換算、單頻 Smith 圖匹配，以及三種 PCB 傳輸線模型。現有數學能力可用，但部分功能仍以文字、下拉選單或靜態示意圖呈現，使用者不容易立刻辨認元件位置、傳播方向、匹配拓撲及輸入數值與圖形的關係。

本次強化的目標是：

1. 讓 T 型與 π 型衰減器在進入頁面後立即可見，不必先展開下拉選單。
2. 讓 RF 傳播、反射、匹配與傳輸線幾何都能以即時 SVG 對應目前輸入及最後有效結果。
3. 保持圖形與數字結果共用同一份計算資料，避免圖形自行計算造成答案漂移。
4. 修正容易誤解的 RF 用詞與錯誤狀態，使結果不會暗示超出模型能力的精度。
5. 保持既有網址、分享參數、三語路由與瀏覽器本機計算架構相容。

成功標準：

- 衰減器頁面不操作下拉選單即可看到並切換 T／π 拓撲。
- 四類 RF 工作流程都有與目前數值同步的工程示意圖。
- 圖形在繁中、簡中、英文、深淺色主題及 320 px 寬度下均可使用。
- 無效輸入不會把最後有效結果偽裝成新的正常結果。
- 既有分享網址與數學行為不因本次視覺強化失效。

## 2. 已選方案與替代方案

### 2.1 採用：專用即時 SVG 元件

每個工程情境使用獨立 SVG 元件，直接接收計算器提供的已格式化數值與狀態。元件可共用外框、電阻／電感／電容符號與狀態提示，但不使用通用節點圖引擎。

此方案可精確控制工程符號、手機版面、三語文字與無障礙語意，同時延續現有被動電路圖的實作方式。

### 2.2 未採用：通用電路圖引擎

以節點、支路與元件資料動態建立任意電路具有長期擴充性，但目前只有少量固定拓撲。引擎會增加座標排版、型別與測試成本，超出本階段需求。

### 2.3 未採用：靜態圖片加文字覆蓋

靜態圖片製作較快，但難以可靠支援深色模式、長數值、三語、手機縮放與螢幕閱讀器，因此不採用。

## 3. 使用者體驗範圍

### 3.1 T／π 型衰減器

π 型計算與圖形已存在，本次不新增重複的工具頁或計算模式，而是改善可發現性與工程資訊呈現。

拓撲選擇由下拉選單改為兩張並列的圖形卡片：

- `T 型網路` 卡片顯示兩個串聯電阻及中央並聯電阻。
- `π 型網路` 卡片顯示兩個並聯電阻及中央串聯電阻。
- 卡片以單選群組語意實作，可用滑鼠、觸控、Tab、方向鍵、Enter 與 Space 操作。
- 選取狀態不能只依賴顏色，另使用邊框、勾選標記與文字。

完整示意圖必須顯示：

- `IN`、`OUT`、接地及系統阻抗 `Z₀`。
- R1、R2、R3 的位置與即時阻值。
- 輸入功率、輸出功率、總耗散功率與各電阻功耗。
- 目前衰減量。

既有 `topology=tee` 與 `topology=pi` 查詢參數保持不變。舊分享網址開啟後，對應卡片與完整圖形必須自動選取。

### 3.2 RF 傳播與波長

新增傳播示意圖，包含訊號方向、波形、λ／4、λ／2、λ 標記、使用者線長端點及結果摘要。圖形同步顯示：

- 頻率。
- 傳播速度。
- 波長。
- 實際線長。
- 電氣角度。
- 傳播延遲。
- 有效相對介電常數或速度因子。

SVG 是示意圖，不作為精密比例尺。當線長超過一個波長時，以重複週期與省略標記表達，不無限拉長畫布；精確值以文字為準。

目前的「相對介電常數」介面名稱改為「有效相對介電常數 εeff」。說明文字必須指出：對均勻介質可直接使用相對介電常數；對 PCB 傳輸線，材料 Dk 通常不等於 εeff，應使用傳輸線工具計算出的有效值或改用速度因子。未輸入 εeff 或速度因子時，沿用自由空間假設。

### 3.3 RF 阻抗與反射

新增由訊號源、`Z₀` 傳輸線和 `ZL` 負載構成的示意圖。圖中包含指向負載的入射波箭頭、返回訊號源的反射波箭頭，以及：

- 參考阻抗 `Z₀`。
- 複數負載 `ZL`。
- Γ 的幅度與相位。
- VSWR。
- Return Loss。

反射箭頭的視覺強度可依 `|Γ|` 調整，但精確數字必須一直顯示。匹配、短路與開路使用專門標示：

- 匹配：`Γ=0`，反射箭頭隱藏或改為零反射虛線佔位。
- 短路：`Γ=-1`，負載端顯示短路符號。
- 開路：`Γ=+1`，負載端顯示開路符號。

此區不重畫迷你 Smith 圖，以免與完整工具重複；結果區提供前往相同語言 Smith 圖工具的連結。第一版不自動把目前 RF 計算器數值帶到另一工具網址。

### 3.4 Smith 圖 L 型匹配電路

現有 Smith 圖、軌跡、數值表與匹配演算法保持不變。每個 `MatchSolution` 結果新增實際電路圖，顯示：

- 負載端 `ZL`、輸入端 `Z₀` 與接地。
- 串聯／並聯元件的實際順序。
- L 或 C 的標準工程符號。
- 理想元件值。
- E12／E24／E48／E96 近似值。

電路圖、文字拓撲、史密斯圖軌跡與「套用方案」動作必須引用同一份 `MatchSolution`／近似解資料，不建立第二套匹配拓撲模型。

### 3.5 PCB 傳輸線幾何圖

現有 Microstrip、對稱 Stripline 與 CPWG 圖形保留，增加即時數值：

- Microstrip：W、h、t。
- 對稱 Stripline：W、b、t。
- CPWG：W、h、t、s。
- 共用：介質 εr、計算出的 Z₀ 與指定長度的電氣角度。

導體、介質與接地層使用不同填色及圖例。幾何圖維持固定示意比例，輸入數值只更新尺寸標籤，不讓極端數值壓縮或放大圖形。mm、mil、µm 切換後，標示使用目前顯示單位，但內部 SI 尺寸及實際計算結果不得改變。

## 4. 元件與檔案邊界

新增或調整的元件依責任拆分：

- 共用圖表外框：統一標題、說明、主題、響應式容器與最後有效結果提示。
- 共用工程符號：只包含無業務狀態的電阻、電感、電容、接地與端點 SVG primitives。
- 衰減器拓撲選擇器：只負責 T／π 卡片與鍵盤互動。
- 衰減器完整圖：只呈現計算器傳入的拓撲、阻值與功耗。
- RF 傳播圖：只呈現傳播結果與介質假設。
- RF 反射圖：只呈現阻抗、Γ 與反射指標。
- Smith 匹配電路圖：只從既有匹配解建立電路視圖。
- 傳輸線幾何圖：依既有模型種類呈現幾何與即時標籤。

不建立通用電路排版 DSL。若多張圖只共用一個簡單符號，符號可以抽取；座標、標籤與拓撲判斷仍留在各自的圖形元件中。

## 5. 資料流與計算邊界

計算器元件是輸入文字與最後有效計算結果的擁有者：

```text
使用者輸入文字
  → 工程數字解析與欄位驗證
  → lib/engineering 計算核心
  → 有型別的有效結果
  → 同一份結果同時供數值表與 SVG 使用
```

SVG 元件不得重新執行衰減器、波長、反射、匹配或傳輸線公式。它們只接收數值、已格式化文字、拓撲枚舉與顯示狀態。

衰減器核心結果增加輸出功率：

`Pout = Pin × 10^(-A/10)`

並維持：

`Pdissipation = Pin - Pout`

當提供輸入功率時，`Pin=0 W` 是有效狀態，輸出功率和所有耗散功率皆為零。衰減量必須大於 `0 dB`，端口阻抗必須大於 `0 Ω`。未提供輸入功率時仍可計算理想阻值，功耗欄位保持省略。

既有查詢字串序列化器繼續作為網址狀態的唯一來源。除 T／π 卡片寫回原有 `topology` 值外，本次不改變既有 URL 欄位名稱或更新語意。

## 6. 無效輸入與最後有效結果

每個受影響的計算器保留兩個概念：目前輸入文字，以及最後一次完整有效的計算結果。

有效輸入時：

- 更新結果表。
- 更新圖形。
- 依既有規則更新分享網址。

無效輸入時：

- 在真正有問題的欄位顯示錯誤，不只把錯誤掛在最後一個欄位。
- 不把無效值送入 SVG。
- 結果表與 SVG 保留最後有效結果。
- 圖形降低視覺強度，並顯示本地化的「目前顯示最後有效結果」。
- 提示使用非打斷式狀態語意，不在每次鍵盤輸入時大量宣讀整個圖表。

首次由非法查詢參數載入且尚無使用者有效結果時，安全預設範例視為最後有效結果，並同時標示目前輸入無效。

## 7. 多語與無障礙

繁中、簡中與英文新增一致的文案鍵，至少涵蓋：

- 每張圖的名稱與簡短說明。
- 輸入端、輸出端、傳播方向、入射波與反射波。
- 最後有效結果提示。
- 有效相對介電常數及材料 Dk 的說明。
- T／π 拓撲卡片的名稱與操作提示。
- 前往 Smith 圖的連結文字。

R、L、C、W、h、b、t、s、Z₀、ZL、Γ、VSWR 等工程符號保持一致，不翻譯。

每張主要 SVG 必須具有 `role="img"`，並提供本地化的 `aria-label`、`<title>` 與 `<desc>`。圖形外保留等價的數值結果；任何重要結果不得只以顏色、箭頭粗細或 SVG 幾何傳達。

拓撲卡片採單選群組語意，焦點樣式清楚。動態更新不強制移動鍵盤焦點。

## 8. 視覺與響應式規則

- 沿用 JK Space 現有色彩變數，不建立第二套主題。
- 工程連線使用目前文字色，主動節點與選取狀態使用 accent 色。
- 不靠顏色單獨區分輸入／輸出、入射／反射或選取狀態。
- SVG 在桌面填滿可用欄寬；小螢幕允許圖形容器內部捲動，但頁面本身不得橫向溢出。
- 長工程數值不得超出 viewBox，也不得與電阻、電感、電容、箭頭或其他標籤重疊。
- 示意圖不宣稱幾何比例精確；必要時在 `<desc>` 或圖外說明標示「非按比例」。

## 9. 測試策略

### 9.1 數學核心

- 6 dB、50 Ω 的 T 型與 π 型參考阻值。
- 輸入功率、輸出功率、總耗散及各電阻功耗的能量一致性。
- `Pin=0 W`、極小正衰減、大衰減、非法阻抗與非有限輸入。
- 波長、半波長、四分之一波長、電氣角度與延遲的往返換算。
- Γ=0、Γ=-1、Γ=+1 及一般複數負載。
- 正常結果中不得出現未處理的 `NaN` 或非物理無窮大。

### 9.2 元件

- T／π 卡片的滑鼠、觸控等價狀態與鍵盤操作。
- 拓撲、阻值、輸入／輸出功率及各電阻功耗同步更新。
- 傳播圖由長度、角度及延遲三種輸入模式取得相同物理結果。
- 反射圖正確呈現匹配、短路、開路與一般失配。
- Smith 匹配圖涵蓋所有串聯／並聯及 L／C 組合，且與解的步驟順序一致。
- 傳輸線圖在三種模型及三種顯示單位下呈現正確標籤。
- 無效輸入保留最後有效結果並顯示狀態提示。

### 9.3 瀏覽器整合

- 舊 `topology=tee|pi` 網址重新整理後還原正確卡片與電路圖。
- 既有 RF、Smith 與傳輸線分享網址保持相容。
- 繁中、簡中與英文路由顯示正確圖表名稱與連結。
- 320、768、1440 px 寬度沒有頁面橫向溢出。
- 長工程數值保持在 SVG 內且不與元件或標籤重疊。
- 深色與淺色主題均有足夠對比。
- RF 計算器前往 Smith 圖的連結保留目前語言。

不以大量像素快照作為主要驗證，避免字型渲染差異造成脆弱測試。主要使用可存取角色、文字、狀態、查詢參數及瀏覽器實際邊界位置驗證；關鍵版面另做人工視覺檢查。

## 10. 實作階段與依賴順序

1. 共用圖表外框、工程符號及狀態規則。
2. 衰減器核心輸出功率與零功率邊界。
3. T／π 圖形卡片及完整衰減器示意圖。
4. RF 傳播示意圖與 εeff 用詞修正。
5. RF 阻抗／反射示意圖與 Smith 工具連結。
6. Smith L 型匹配電路圖。
7. 傳輸線即時幾何標籤。
8. 三語內容更新、完整整合測試、獨立審查與 Preview 驗證。

每個階段必須產生可獨立測試的結果；詳細檔案與 TDD 步驟留待本規格批准後的實作計畫定義。

## 11. 驗收標準

- 衰減器頁面直接顯示 T／π 兩種圖形選擇，且不需要展開下拉選單。
- T／π 完整圖顯示正確 R1、R2、R3 位置、阻值及功耗。
- RF 傳播圖顯示 λ／4、λ／2、λ、線長、角度與延遲。
- RF 反射圖顯示 Z₀、ZL、Γ、VSWR、Return Loss 及正確極限狀態。
- Smith 匹配結果具有與實際解一致的 L 型電路圖。
- 三種 PCB 傳輸線圖顯示目前單位下的實際尺寸、εr、Z₀ 與電氣角度。
- 無效輸入期間，圖形清楚標示最後有效結果，且不顯示非法值。
- 繁中、簡中與英文功能一致，沒有缺少翻譯鍵。
- 既有工具與分享網址全部相容。
- 所有相關單元、元件、瀏覽器與正式建置驗證通過。
- 獨立整體審查沒有未處理的 Critical 或 Important 問題。

## 12. 非目標

本次不包含：

- 新增另一個獨立 π 型衰減器工具頁。
- 不等輸入／輸出阻抗衰減器、Bridged-T 或平衡衰減器。
- S1P／S2P 匯入、頻率掃描或寬頻最佳化。
- 元件 Q、ESR、ESL、SRF、容差蒙地卡羅或 PCB 寄生模型。
- 傳輸線損耗、頻散、阻焊、粗糙度或完整場求解。
- 改造 Engineering Converter 的 RF 功率分頁。
- 建立通用電路圖 DSL、Canvas 引擎或新增第三方圖表套件。

## 13. 發布策略

功能在獨立分支完成後執行完整驗證與獨立程式碼審查，再建立 GitHub PR 與 Vercel Preview。Preview 必須覆蓋三語、手機、深淺色、T／π、反射極限及三種傳輸線圖形；全部通過後才合併到 `main` 並觸發正式部署。
