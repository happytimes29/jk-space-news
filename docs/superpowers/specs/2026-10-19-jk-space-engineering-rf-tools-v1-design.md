# JK Space 電子與 RF 工程工具第一版設計規格

**日期：** 2026-10-19  
**狀態：** 對話範圍已確認，待站主審閱書面規格  
**範圍：** JK Space 公開網站的第一版電子與高頻電路工具；不包含 VNA 檔案解析或寬頻 RF 最佳化

## 1. 背景與目標

JK Space 的 Tools 將從單一 PCB 比對工具擴充為「Electronics & RF Workbench」，服務電子、PCB、硬體與 RF 工程師的日常快速計算。第一版要兼顧三個目的：

1. 讓使用者不必開啟桌面模擬器，就能在瀏覽器完成常用工程換算與初步設計。
2. 讓每個結果同時提供公式、假設、限制與可分享網址，而不是只有一個沒有脈絡的數字。
3. 以共用且可測試的數學核心支援後續 S1P／S2P、頻率掃描及更進階匹配功能。

主要使用者是電子、PCB、硬體與 RF 工程師；學生與 Maker 可以使用，但介面不以教科書式長流程取代工程效率。

成功標準：

- 所有計算都能在瀏覽器本機完成，不需要帳號、後端或付費 API。
- 第一版提供五個工具入口，涵蓋一般工程計算與單頻 RF 設計。
- 史密斯圖能接受手動輸入的單一頻率複數阻抗，顯示阻抗狀態並產生 L 型匹配方案。
- 計算核心與畫面元件分離，重要公式有獨立單元測試及已知參考案例。
- 繁中、簡中與英文都有固定網址、完整介面及對應的 SEO／GEO metadata。
- 錯誤輸入、數學奇異點及超出模型適用範圍時，不輸出具有誤導性的正常結果。

## 2. 已選架構與替代方案

### 2.1 採用：共用計算核心＋五個獨立工具頁

網站保留 `/tools` 作為工具集合頁。十類計算能力依工作情境整合成五個入口，每個入口都有介紹頁與互動應用頁。所有工具共用數值解析、單位、複數、標準元件值與格式化模組。

此方案在可搜尋的獨立主題頁與不重複工程邏輯之間取得平衡，也是第一版的固定方向。

### 2.2 未採用：每個小計算器各自一頁

優點是單頁主題單純；缺點是會產生十個以上高度重複的小頁面，單位規則、輸入驗證及多語文案容易漂移，導覽也會過度零碎。

### 2.3 未採用：全部放在單一大型工作台

優點是所有功能集中；缺點是手機操作、載入、分享、SEO 主題及錯誤隔離都較差，史密斯圖的複雜度也會壓過簡單計算器。

## 3. 第一版功能範圍

### 3.1 Engineering Converter

路徑：

- 繁中：`/tools/engineering-converter/app`
- 簡中：`/zh-cn/tools/engineering-converter/app`
- 英文：`/en/tools/engineering-converter/app`

包含：

- 電壓、電流、電阻、電容、電感、頻率、時間、功率及長度換算。
- `p`、`n`、`µ`／`u`、`m`、`k`、`M`、`G` 工程前綴。
- `4k7`、`2R2`、`100n`、`3p3` 等常見工程輸入。
- 一般小數、科學記號、工程記號及 SPICE 風格輸出。
- RF 功率換算：dBm、dBW、W、mW、Vrms、Vpeak、Vpp、Irms。
- RF 電壓與功率換算必須指定 50 Ω、75 Ω或正數自訂阻抗。

### 3.2 Passive Circuit Calculator

路徑同樣使用三語前綴，slug 為 `passive-circuit-calculator`。

包含：

- 分壓電阻：任選 Vin、Vout、R1、R2 的設計情境，計算實際輸出、分壓電流與個別功耗。
- E12／E24／E48／E96 標準阻值建議，依相對輸出誤差排序，顯示理想值與實際值差異。
- 可選後級輸入阻抗及電阻容差；顯示負載效應與最差情況輸出範圍。
- RC 時間常數及低通／高通截止頻率。
- LC 諧振頻率、RLC 串聯／並聯的基本諧振、Q 值與頻寬。
- 電容抗 `Xc` 與電感抗 `Xl`。
- RF 衰減器：相同輸入／輸出參考阻抗下的 T 型與 π 型電阻網路，輸入衰減 dB 與系統阻抗，輸出理想阻值及各支路功耗提示。

第一版不處理任意不等端口阻抗的 Bridged-T、元件寄生參數或頻率相依電阻模型。

### 3.3 RF Quick Calculator

slug 為 `rf-calculator`，包含：

- 自由空間波長、介質中的近似波長、半波長、四分之一波長。
- 物理長度、電氣角度、相位延遲與傳播時間互換。
- 複數阻抗 `Z = R + jX` 與導納 `Y = G + jB` 互換。
- 參考阻抗歸一化及反歸一化。
- 反射係數 Γ 的直角座標、幅度／相位及 dB 表示。
- S11、VSWR、Return Loss 與 Mismatch Loss 換算。
- 頻率、傳播速度因子或有效介電常數的輸入假設會明確顯示。

### 3.4 Smith Chart & Matching

slug 為 `smith-chart`。第一版已確認的硬邊界：

- 只接受手動輸入。
- 只處理單一頻率。
- 輸入為被動負載的複數阻抗 `R + jX`。
- 參考阻抗預設 50 Ω，可選 75 Ω或輸入正數自訂值。
- 不接受 S1P／S2P、CSV 或 VNA 檔案。
- 不做頻率掃描、寬頻最佳化、多級匹配、穩定圓、增益圓或雜訊圓。

史密斯圖必須提供：

- 阻抗格線與導納格線切換；標示實軸、中心點、開路及短路位置。
- 目前負載點、目標中心點及選定網路的移動軌跡。
- 同步讀值：Z、Y、歸一化阻抗、Γ、S11、VSWR、Return Loss、Mismatch Loss。
- 允許依序加入理想串聯 R／L／C 或並聯 R／L／C，輸入正數元件值並立即重算。
- 操作序列可復原、重做、刪除及重設；不需要用拖曳點位作為唯一輸入方式。
- 可將目前設定編碼到查詢字串，複製分享網址。
- 可匯出包含格線、軌跡、頻率、參考阻抗及結果摘要的 PNG。

L 型匹配求解器必須：

- 以目前頻率、參考阻抗及複數負載為輸入。
- 只使用理想、無損的 L 與 C，產生所有可行的二元件 L 型拓撲，而不是只顯示第一組解。
- 每組解顯示串／並聯順序、元件種類、理想值、匹配後阻抗及史密斯圖軌跡。
- 顯示低通／高通性質及匹配網路示意圖。
- 可選擇 E12／E24／E48／E96 近似值，重新計算近似後的結果與誤差；理想解與標準值解不得混為同一數值。
- 拒絕負電阻、非有限數值、非正頻率或非正參考阻抗；零阻抗、開路及接近奇異點的情況顯示專門說明。
- 清楚聲明結果是指定頻率下的理想窄頻匹配，不包含元件 Q、ESR、SRF、PCB 走線、封裝及寄生效應。

### 3.5 Transmission Line

slug 為 `transmission-line`，第一版包含：

- Microstrip。
- 對稱 Stripline。
- Coplanar Waveguide with Ground（CPWG）。
- 從幾何尺寸求特性阻抗的正向計算。
- 以目標阻抗求線寬的反向求解；數值求解失敗時顯示可操作的錯誤，不沿用前一次結果。
- 有效介電常數、相速度、波長、單位長度延遲及指定長度的電氣角度。
- 幾何輸入至少包含線寬、介質厚度、銅厚與相對介電常數；CPWG 另包含兩側相同的 gap。
- 常見單位 mm、mil、µm 可切換，但內部全部使用 SI 單位。
- 將公式模型、假設、建議適用範圍及與板廠／場求解器可能出現差異的原因顯示在頁面上。

第一版只做準靜態閉式公式的初步估算，不計算粗糙度、頻散、表面處理、銅箔梯形、阻焊、連接器、轉角、過孔或完整導體／介質損耗。固定使用下列模型，程式註解、工具說明及基準測試必須指向同一來源，不能混用未標明來源的網路公式：

- Microstrip：Hammerstad–Jensen 的準靜態特性阻抗、有效介電常數及有限導體厚度修正；不套用 Kirschning–Jansen 或其他頻散模型。
- 對稱 Stripline：Michael Steer《Microwave and RF Design II》3.7.1 節、式 (3.42)–(3.44) 的有限導體厚度 closed-form；只接受導體位於兩接地平面中央的對稱結構。此項在獨立審查後取代原先不符合該 shielded-stripline 幾何的 Wheeler 1965 引用。
- CPWG：Qucs Technical Guide 第 12.1.2–12.1.3 節、式 (12.10)–(12.18) 的有限厚度介質、背面接地、準靜態 conformal-mapping 模型與一階導體厚度修正；不加入該文件第 12.1.4 節的頻散式。

## 4. 資訊架構與內容模型

`/tools` 顯示五個新工具卡片及既有 PCB 工具。每個新工具都有：

1. 內容介紹頁 `/tools/{slug}`。
2. 互動應用頁 `/tools/{slug}/app`。
3. 簡中與英文對應路由。

介紹頁沿用現有 `content/tools` frontmatter、`ToolDetailPage`、JSON-LD、canonical 與 `hreflang` 架構。五個工具的繁中原文與簡中、英文譯文一起發布，譯文狀態在站主批准部署前保持 `reviewed`，部署時才升級為 `published`。

互動應用頁的語言跟隨 URL，不能再像既有 PCB 應用只提供繁中介面。frontmatter 中的 `appUrl` 保存無語言前綴的邏輯路徑，`OpenToolLink` 依目前 locale 產生最終網址；不在三份內容重複硬編碼不同 URL。語言切換器只能連到確實存在的對應工具頁。

每個應用路由在 server 邊界查詢對應工具內容與目前 build visibility。工具或譯文仍為 `reviewed` 時只在 Preview 可開啟；production 必須回傳 404，而不是因靜態應用路由存在就提前公開。

## 5. 共用計算核心

計算核心放在獨立的 `lib/engineering` 邊界，不依賴 React、DOM、目前語言或 CSS。建議單元：

- `quantity`：工程數字解析、SI 單位正規化與顯示格式化。
- `complex`：複數四則運算、極座標與直角座標轉換。
- `standard-values`：E12／E24／E48／E96 阻值與最鄰近值搜尋。
- `passive`：分壓、RC、LC、RLC 及衰減器。
- `rf`：功率、波長、阻抗、導納、Γ、VSWR 及損耗。
- `smith`：歸一化阻抗與 SVG 座標映射、元件步驟及軌跡取樣。
- `matching`：理想單頻 L 型匹配解集合與標準值重算。
- `transmission-line`：三種傳輸線模型與反向數值求解。

所有公開函式使用明確型別及具單位名稱的欄位。核心內部採 SI 單位、Ω與 Hz；畫面層才處理使用者選擇的顯示單位。角度在公開輸入／輸出採 degree，內部三角函式轉為 radian。

除格式化之外，禁止以字串作為核心數學輸入；畫面解析失敗後不得呼叫計算核心。

## 6. 互動與狀態設計

- 初次進入顯示一組可理解的合成範例，不顯示空白圖表或 `NaN`。
- 使用者輸入在前端驗證後即時計算；複雜的反向線寬求解可在短暫 debounce 後執行。
- URL 查詢參數只保存公開的計算設定，不保存識別資訊；非法、未知或超長參數忽略並回到安全預設值。
- 更新 URL 使用 `replaceState`，避免每次輸入都污染瀏覽器返回歷史。
- 數值輸入保留使用者正在編輯的文字；結果區只顯示最後一次完整且有效的計算。
- 每個工具提供「重設範例」、「複製結果」與「複製分享網址」。
- 不使用 Local Storage 保存計算值。重新整理可由查詢參數還原，無查詢參數時回到範例。
- Analytics 只記錄公開工具 slug 及非數值操作名稱，不記錄阻抗、頻率、尺寸、網址查詢字串或計算結果。

## 7. 數值、錯誤與安全規則

- 禁止 `NaN`、`Infinity`、空字串、負頻率、負參考阻抗及除以零進入正常結果。
- 顯示精度依數量級自動調整，但核心保留完整浮點值；不得用已格式化字串繼續計算。
- 比較與奇異點判斷使用集中定義的容差，不在元件中散落不同 magic number。
- 非被動負載、模型不支援的尺寸比例或無法收斂的反向求解回傳結構化錯誤碼，再由三語介面轉成文字。
- 傳輸線輸入超出公式建議範圍時，顯示醒目警告；可計算不代表符合製造能力或實際阻抗。
- 工具結果明確標示「工程估算／理想模型」，不取代 SPICE、電磁場求解、VNA 實測、元件 datasheet 或板廠阻抗控制。
- 所有運算在瀏覽器本機執行，沒有檔案上傳、外部 API 或動態程式碼執行。

## 8. 視覺與無障礙

工具沿用 JK Space 深色／淺色主題及現有設計語言，不建立與網站脫節的第二套品牌。

- 桌面版計算器採「左側輸入、右側結果／圖表」；行動版依序堆疊。
- 史密斯圖使用響應式 SVG，格線、資料點及軌跡有足夠對比；顏色之外再用形狀、線型及文字區分。
- 每個輸入具有可見 label、單位及錯誤提示，錯誤訊息透過 `aria-describedby` 關聯。
- 計算結果更新使用不打斷輸入的狀態區；不把每次鍵盤輸入都宣讀成大量內容。
- 所有操作可用鍵盤完成；復原、刪除、拓撲選擇與匯出不依賴 hover。
- 圖表下方提供等價的數值表格，讓螢幕閱讀器使用者不必依賴 SVG 圖形理解結果。

## 9. 多語言、SEO 與 GEO

- 介面文字加入現有 zh-TW、zh-CN、en 字典，三語鍵集合驗證仍必須通過。
- 單位符號、公式、R/L/C、S11、VSWR 等專有符號保持一致；說明文字與警告完整翻譯。
- 五個介紹頁及五個應用頁各有 locale 對應的 title、description、canonical、`hreflang` 與 Open Graph 資訊。
- sitemap 收錄正式發布的介紹頁與可索引應用頁。
- 每個介紹頁提供問題、輸入、公式、範例、結果解讀、限制及最後更新日期。
- `SoftwareApplication` JSON-LD 的操作 URL 指向該 locale 的應用頁，`inLanguage` 與頁面一致。
- 不以大量重複 FAQ、隱藏內容或關鍵字堆疊取得搜尋曝光。

## 10. 測試策略

### 10.1 單元測試

- 工程記號解析、SI 前綴、無效輸入及格式化回轉。
- 複數四則運算、極座標與奇異點。
- E 系列生成、最鄰近值、邊界值與排序穩定性。
- 分壓、負載效應、功耗、公差、RC／LC／RLC 與衰減器參考案例。
- dBm／功率／電壓、波長、Z／Y／Γ／VSWR／Return Loss 的雙向換算與 round-trip。
- 史密斯座標中心、開路、短路、純電阻、純電抗及正負半平面。
- 串／並聯元件步驟與軌跡端點。
- L 型匹配所有可行拓撲、匹配後中心點、標準值重算及拒絕無效負載。
- 三種傳輸線模型的公開參考案例、單調性及反向求解 round-trip。

浮點測試使用物理上合理的絕對／相對容差，不以格式化後字串掩蓋計算誤差。每種高頻公式至少有一個來源明確的基準案例，並記錄來源與公式版本。

### 10.2 元件與整合測試

- 輸入單位切換不改變底層物理值。
- 無效欄位顯示錯誤且保留最後有效結果。
- 查詢參數載入、更新、非法參數回退與複製連結。
- 三語頁面使用正確字典、返回路徑及 metadata。
- 史密斯圖步驟新增、復原、重做、刪除、重設與方案套用。
- SVG 數值表格與圖形呈現相同結果。
- PNG 匯出不遺漏格線、軌跡與摘要。

### 10.3 E2E 與回歸

- 五個繁中、簡中與英文介紹／應用網址可直接開啟與重新整理。
- 手機與桌面關鍵流程可完成，不產生水平溢位。
- 使用範例完成一次分壓、RC、RF 快算、L 型匹配及傳輸線計算。
- canonical、`hreflang`、sitemap、站內搜尋與語言切換包含正確路徑。
- 既有 PCB 工具、多語內容、RSS、retired-news guard 及全站 production build 不回歸。
- 完整 `npm run verify` 與 `npm run test:e2e` 通過後才可進入發布審批。

## 11. 分階段交付

### Phase 1：共用核心與基礎介面

建立 quantity、complex、standard-values、共用表單／結果／錯誤元件及查詢參數規則，先用測試鎖定數值契約。

### Phase 2：一般電子工具

完成 Engineering Converter、Passive Circuit Calculator 與 RF Quick Calculator，加入三語內容與介紹頁。

### Phase 3：史密斯圖與單頻匹配

完成 SVG 史密斯圖、手動單點輸入、元件步驟、L 型匹配方案、標準值重算、分享與 PNG 匯出。

### Phase 4：傳輸線工具

完成 Microstrip、Stripline、CPWG 正向計算與目標阻抗反向求解，補齊公式來源、適用範圍及警告。

### Phase 5：整合與發布候選

完成三語 SEO／GEO、全站搜尋、sitemap、E2E、可用性檢查與 production build。提供本機或 Vercel Preview；只有站主明確批准才合併與正式部署。

## 12. 第一版非目標與後續方向

第一版不包含：

- S1P／S2P Touchstone 匯入或匯出。
- VNA、頻譜分析儀或其他儀器連線。
- 頻率掃描、多點軌跡或多埠 S 參數。
- Stub、四分之一波長、多級 π／T 或寬頻最佳化匹配。
- 元件廠牌資料庫、即時庫存、價格或供應商 API。
- 實際元件 Q、ESR、SRF、封裝與 PCB 寄生模型。
- RF cascade、Noise Figure、IP3、P1dB 或穩定性分析。
- 2D／3D 電磁場求解及製造阻抗保證。
- 帳號、雲端儲存、專案協作或計算歷史同步。

後續版本依序考慮 Touchstone 本機解析、頻率軌跡、Stub matching、實際元件模型及 RF chain budget。任何檔案功能仍優先採瀏覽器本機處理。

## 13. 發布與回滾

- 功能在獨立分支開發，不直接修改 production branch。
- 開發中工具內容使用 `reviewed`，不在正式 production build 公開；站主確認後才改為 `published`。
- 正式發布前保存通過驗證的 commit、Preview URL、關鍵計算案例與已知限制。
- 若整套工具造成回歸，可回退該功能 PR；若只有單一工具有問題，可把該工具內容降為非公開並移除入口，不影響既有 PCB 工具。
- 數學錯誤修正必須增加失敗案例測試，不能只調整畫面結果。

## 14. 驗收清單

第一版只有在以下條件全部成立時才視為完成：

- 五個工具入口及其三語介紹／應用頁存在。
- 所有計算在本機執行，開發者工具中沒有計算資料 API 請求。
- 史密斯圖符合手動、單頻、複數阻抗與 L 型匹配的既定範圍。
- 公式來源、輸入假設、適用範圍與非理想限制在頁面可見。
- 無效輸入、奇異點及模型外輸入有三語錯誤或警告。
- 分享網址能還原等價計算狀態，且 Analytics 不收集參數值。
- 鍵盤、手機及數值替代內容可完成核心操作。
- 計算、介面、路由、metadata、sitemap、搜尋及既有功能測試全部通過。
- 站主檢視 Preview 並明確批准合併及部署。
